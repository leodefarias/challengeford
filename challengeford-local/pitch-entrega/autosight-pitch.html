Arquitetura TOGAF

Visão da Arquitetura
Perspectiva Estratégica
  • Automatizar coleta e análise de catálogos competitivos no BR
  • Reduzir ciclo de 80h para <4h com ≥90% acurácia
  • Garantir rastreabilidade e zero alucinação em cada atributo
  • Mobile-first para acesso em campo pelos analistas Ford
Arquitetura de Negócio
Mudança de Processo
  • AS-IS: coleta manual (PDF, sites), planilhas, 80h/mês
  • TO-BE: trigger automático → extração LLM → validação → Oracle
  • Analista recebe dados prontos em <4h via mobile
  • Chat RAG substitui busca manual em catálogos
Arquitetura de Sistema
Componentes e Comunicação
  • React Native → REST API Java (port 8080) via JWT
  • Java Spring Boot → Python FastAPI (port 8000) via HTTP interno
  • Python FastAPI → Claude Sonnet + ChromaDB (RAG)
  • Oracle 12c: 8 tabelas + 3 views. Flyway migrations.
  • Nginx: TLS termination + reverse proxy
Arquitetura de Tecnologia
Infraestrutura
  • Docker Compose: 3 containers (Java, Python, Oracle)
  • Monitoramento: logs estruturados (Logback), healthchecks
  • Segurança: 15 camadas — TLS, JWT, AES-256, RBAC, Rate Limit
  • Escalabilidade: stateless API → horizontal scale ready
