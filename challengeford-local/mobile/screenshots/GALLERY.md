# Galeria de telas — AutoSight Mobile

Demonstração visual de todas as telas para entrega Sprint 3.  
HTML interativo: abra [gallery.html](gallery.html) no navegador.

## Como capturar screenshots reais (recomendado para Teams)

```bash
cd mobile
npx expo start
# Emulador Android ou Expo Go → percorra cada tela → Print Screen
# Salve PNGs nesta pasta com os nomes abaixo
```

| Arquivo sugerido | Tela |
|------------------|------|
| `01-login.png` | Login |
| `02-home.png` | Home / ficha |
| `03-comparativo.png` | Comparativo |
| `04-score.png` | Score |
| `05-gaps.png` | Gaps |
| `06-chat.png` | Chat RAG |
| `07-timeline.png` | Timeline |
| `08-pending.png` | Itens pendentes |
| `09-status-agent.png` | Status do agente |
| `10-security-events.png` | Eventos de segurança |
| `11-score-settings.png` | Configuração de score |
| `12-drawer.png` | Menu / drawer |

Enquanto PNGs reais não estiverem anexados, a [gallery.html](gallery.html) serve como **demo visual** das 12 telas (wireframe fidelidade de produto).
